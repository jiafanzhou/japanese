## 免费音源三件套（我唯一替代不了的部分）

1. **いろどり Irodori**　https://www.irodori.jpf.go.jp/
   日本国际交流基金出的正规教材。PDF + 全部音频免费下载，有中文版翻译。
   → 我们的**主音源**。我讲解，你听它的音频跟读。

2. **NHK World「やさしい日本語」Easy Japanese**　https://www.nhk.or.jp/lesson/
   48 课免费入门课程，有中文界面、音频、剧情。适合睡前/通勤被动听。

3. **OJAD 音高重音词典**　https://www.gavo.t.u-tokyo.ac.jp/ojad/
   东京大学做的，输入任何词或句子，画出音高曲线。中文母语者最容易带普通话声调，
   这个工具是解药。查词发音另外用 **Forvo**（forvo.com）。

进阶备用：**NHK Web Easy**（简易新闻带朗读）、**Nihongo con Teppei for Beginners**（播客，
每集 3～5 分钟，跑步时听）、**日本語の森** YouTube。

## 怎么跟我上课

**开新对话时，第一句话说：**
> 读一下 日语/进度.md，继续上课

我会接着上次的进度往下讲。

**平时可以直接说：**
- 「继续」→ 下一课
- 「我 て形 不熟，出 30 道题」→ 针对性练习
- 「批改：<你写的句子>」→ 逐句改，并归类错因写进错题本
- 「拆解这句：<在野外遇到的日语>」→ 语法解剖
- 「陪我对话，你演便利店店员」→ 限定在我学过的语法范围内的角色扮演

**我做不到的两件事，别指望我：**
- 听你的发音（这个终端没有音频）→ 用 OJAD + Forvo + 跟读 Irodori 音频
- 练实时口语反应 → 第 3 个月起在 italki 找日本老师，每周 30 分钟即可（€10～20/时）

## 12 个月路线图

- **第 1 个月**　假名（2 周）→ 数字、时间、指示词（これ/それ/あれ）、名词句（Aは Bです）
- **第 2～3 个月**　动词 ます形、助词 は/が/を/に/で/へ、形容词两类（い形/な形）、存在句（あります/います）
- **第 4～6 个月**　て形（最重要的一关）、た形、ない形、辞书形；可能/意志；授受动词
- **第 7～9 个月**　自他动词、被动/使役、条件句（と/ば/たら/なら）、简体与敬体切换
- **第 10～12 个月**　敬语入门（丁寧/尊敬/謙譲）、长文阅读、写作输出
- **贯穿全程**　每天 20 个新词 + 复习；每周一次写作批改；汉字只学"读音"不学"写法"

## 中文母语者专属注意事项

**优势**——汉字不用从零学，阅读会远远跑在听说前面。别被这个假象骗了：**读得懂 ≠ 听得懂**。

**四个坑**（贯穿全程反复提醒）：
1. **同形异义词**——手紙=信，勉強=学习，娘=女儿，汽車=火车，大丈夫=没关系，階段=楼梯
2. **一字多音读**——生 → せい/しょう/なま/い/う/き。**永远不要看字猜音**，每个词单独记读音
3. **助词** は/が/を/に/で——中文没有对应物，是真正的难点，靠大量输入形成语感
4. **音高重音**——橋/箸/端 都是 hashi。中文声调会本能地带进来，必须早期用 OJAD 校准
