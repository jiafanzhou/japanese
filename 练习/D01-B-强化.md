## 练习 1 ｜ 速读三连（专治认读慢）

同一串字念三遍，每遍计时。**目的不是一次念快，是看你能不能越念越快。**

```
第一遍 →  え　お　あ　う　い　　お　い　え　あ　う
第二遍 →  う　あ　い　お　え　　い　う　お　え　あ
第三遍 →  お　え　う　い　あ　　あ　う　い　え　お
```

| | 秒数 |
|---|---|
| 第一遍 | ______ |
| 第二遍 | ______ |
| 第三遍 | ______ |

**判定：第三遍 ≤ 10 秒**，就算达标（你的起点是 14.7）。
念的时候**不许在心里翻译成罗马音再念**——看到字直接出声。这一步是本练习的全部意义。

## 练习 2 ｜ 字源反查（把工具练顺手）

不看表，填空。左右两个方向都要能走通。

**A. 假名 → 汉字**

```
あ ← ___     い ← ___     う ← ___     え ← ___     お ← ___
```

**B. 汉字 → 假名（这是默写时真正走的方向）**

```
於 → ___     宇 → ___     安 → ___     衣 → ___     以 → ___
```

**C. 中文音 → 假名（跳过汉字，直接反应）**

```
yī → ___     ān → ___     yū → ___     yǐ → ___     yǔ → ___
```

> 目标是**将来 C 组不用经过 A、B 就能写出来**。今天写不到那步没关系，字源是拐杖，走稳了自然会扔。

## 练习 3 ｜ 拍感（★ 本轮重点，中文母语者最容易翻车的地方）

日语里**多一拍就是另一个词**。中文没有这个机制，所以要专门练。

**A. 先念下面三对，每对的两个词必须听得出长度不同：**

| 短 | 长 | 差别 |
|---|---|---|
| いえ（2 拍）家 | いいえ（3 拍）不、不是 | 差一拍，意思完全无关 |
| おい（2 拍）外甥 | おおい（3 拍）多的 | 同上 |
| え（1 拍）画、柄 | ええ（2 拍）嗯、是的 | 同上 |

**念法：一拍一拍，长度均等，像节拍器。**
`い-い-え` 是三下，**不是**把「い」拖长成两下半。

**B. 边拍手边念**，一个假名拍一下手：

```
1. あおい      拍 ___ 下
2. おおう      拍 ___ 下
3. いいえ      拍 ___ 下
4. うえ        拍 ___ 下
5. おおい      拍 ___ 下
```

**C. 判断题：** 下面每句话对不对？

```
1. 「おおい」和「おい」只是语气不同，意思一样。          （ 对 / 错 ）
2. 「いいえ」念的时候，第一个い要拖长，第二个い一带而过。  （ 对 / 错 ）
3. 日语每个假名占的时间长度基本相等。                    （ 对 / 错 ）
```

## 练习 4 ｜ う 段专项（你的历史错点）

**动作要领复习：** 发中文「衣」的音 → 嘴唇宽度锁死不许动 → 只把舌头往后缩。

对着镜子念，全程盯住嘴唇：

```
い　う　い　う　い　う　　（嘴唇宽度不许有任何变化）
うえ　うお　あう　いう　おおう
```

**自检：** 念完这一组，嘴唇有没有一次撅出去过？　（ 有 / 没有 ）

> 有 → 回到「い→う」慢速交替，直到六遍嘴唇纹丝不动。
> 这一列的音（う/く/す/つ/ぬ/ふ/む/ゆ/る）后面会跟你一辈子，现在校准最便宜。

# 答案（做完再看）

**练习 1**
第一遍：e o a u i / o i e a u
第二遍：u a i o e / i u o e a
第三遍：o e u i a / a u i e o

**练习 2**
A. あ←安　い←以　う←宇　え←衣　お←於
B. 於→お　宇→う　安→あ　衣→え　以→い
C. yī→え　ān→あ　yū→お　yǐ→い　yǔ→う

> 注意 C 组最容易错的是 **yī→え** 和 **yū→お**。「衣」念 yī 却对应 e，「於」念 yū 却对应 o——这两个是字源法里唯二不太顺的，单独记。

**练习 3**
B. 1. あおい 3 下　2. おおう 3 下　3. いいえ 3 下　4. うえ 2 下　5. おおい 3 下
C.
1. **错** —— おい=外甥，おおい=多的，毫无关系的两个词
2. **错** —— 两个 い 长度完全相等，各占一拍。「拖长」是中文的处理方式，日语是「数拍子」
3. **对** —— 这就是「拍（モーラ）」的定义，日语节奏的地基

**练习 5**

| 词 | 读音 | 拍数 | 汉字 | 中文 | 答案 |
|---|---|---|---|---|---|
| あおい | a-o-i | 3 | 青い | 蓝色的 | C |
| いいえ | i-i-e | 3 | —— | 不、不是 | F |
| うお | u-o | 2 | 魚 | 鱼 | A |
| うえ | u-e | 2 | 上 | 上面 | B |
| いう | i-u | 2 | 言う | 说 | D |
| おおう | o-o-u | 3 | 覆う | 覆盖 | E |

> 补充：「鱼」平时说 **さかな**，うお 多用在合成词里（魚市場 うおいちば）。现在知道有这么个读法就行。
> 「いいえ」是极少数**没有汉字**的常用词之一，直接记假名。

**练习 6**
1. お え う い あ
2. おおい 3 拍　／　おい 2 拍
3. 字源 **宇**，嘴唇 **扁平（不圆）**
4. あおい
