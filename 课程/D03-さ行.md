# Day 3：さ し す せ そ

> 上课日期：2026-08-26

## 一、五个字 + 字源

| 假名 | 读音 | 字源汉字 | 日语音读 | 粤语 | 普通话 |
|---|---|---|---|---|---|
| **さ** | sa | **左** | サ sa | zo | zuǒ |
| **し** | **shi** ⚠️ | **之** | シ shi | zi | zhī |
| **す** | su | **寸** | スン sun | cyun | cùn |
| **せ** | se | **世** | セ se | sai | shì |
| **そ** | so | **曽** | ソ so | zang | céng |

助记串：**左之寸世曽**

> 复习字源法的正确用法：汉字只给**形**，不给音。音由五十音图网格决定。
> `要写 se → さ行×え段，第 3 行第 4 格 → 串「左之寸世曽」第 4 个 = 世 → 草写 → せ`

### 拆字法
| 假名 | 拆解 |
|---|---|
| さ | 左 → 上面「一 + 丿」，下面的「口」草掉，留个弯 |
| し | 之 → 一笔从上拉到底，尾巴向右钩 |
| す | 寸 → 一横 + 一竖钩，中间打个圈（「寸」那个点被草成圈） |
| せ | 世 → 「世」字草写，一横贯穿，右下拖一笔 |
| そ | 曽 → 「曽」上半部的折笔草写，一笔之字形下来 |

---

## 二、⚠️ 本课头号坑：し 不是 si，是 shi

**さ行 = sa / shi / su / se / so**

`し` 是五十音图的**第一个破格**。整张表一共三个破格：

| 破格 | 出现在 | 学习日 |
|---|---|---|
| **し shi**（不是 si） | さ行 い段 | **D3 本课** |
| **ち chi**（不是 ti） | た行 い段 | D4 |
| **つ tsu**（不是 tu） | た行 う段 | D4 |
| （**ふ fu**，不是 hu） | は行 う段 | D6 |

规律：**い段和う段容易把辅音"拧歪"**，因为 i / u 这两个元音舌位最高，最容易把前面的辅音带跑。

---

## 三、⚠️ 发音坑：し 是「西」，不是「诗」

中文母语者最爱把 `し` 读成卷舌的 `诗 shī`。**错。**

| | 舌头位置 | 中文对应 |
|---|---|---|
| 中文 `诗 shī` | 舌尖**卷起**顶硬腭 | ❌ 太靠后 |
| 中文 `西 xī` | 舌面贴硬腭，舌尖朝下 | ✅ 就是它 |
| 日语 `し` | 同「西」，略往后一点点 | ✅ |

**记法：し ≈ 中文「西」。** 罗马音写 `shi` 只是拼写习惯，别被 sh 带去卷舌。

同理提前打预防针：後面的 `しゃ しゅ しょ` 也全是「西」系，不是「沙」系。

---

## 四、⚠️ 发音坑：す 的两件事

**① う段不圆唇**（老规矩，第三次复查）
`す` = su，嘴唇扁。从 `い` 起手，宽度不动只缩舌头。

**② 词尾的 す 会「清化」** —— 元音 u 被吞掉，只剩气声
- `です` 听起来像 **des**，不是「德斯」
- `ます` 听起来像 **mas**，不是「马斯」

现在只要**听得出**就行，不要求会用（D4 之后才碰句子）。
同一个现象也发生在 `し` 上：`しています` → 「shte-imas」。

## 五、形近对（本课新增两组）

### ★ さ / き —— 本课最容易混
```
さ  = 一横 + 弯     ← 一根横
き  = 两横 + 弯     ← 两根横
```
**数横线：一横 sa，两横 ki。**

### ★ し / つ（D4 预告）
```
し  竖着下来再钩    ← 一笔，纵向
つ  横着过去再钩    ← 一笔，横向
```
**竖的是 し，横的是 つ。** D4 学到 つ 时再合练。

### 顺带复习 D2
`こ`（趴着，己）/ `い`（站着，以）
