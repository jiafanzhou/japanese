# Day 4：た ち つ て と

> 上课日期：2026-08-27
> 本课地位：**一次干掉五十音图剩下的两个破格**（ち chi / つ tsu），破格只剩 ふ fu 一个（D6）。

## 一、五个字 + 字源

| 假名 | 读音 | 字源汉字 | 日语音读 | 普通话 |
|---|---|---|---|---|
| **た** | ta | **太** | タイ tai | tài |
| **ち** | **chi** ⚠️ | **知** | チ chi | zhī |
| **つ** | **tsu** ⚠️ | **川** | セン sen | chuān |
| **て** | te | **天** | テン ten | tiān |
| **と** | to | **止** | シ shi | zhǐ |

助记串：**太知川天止**

> 老规矩：汉字只给**形**，不给音（看「川」猜不出 tsu，音由网格给）。
> 完整链条：`要写 to → た行×お段 → 第 4 行第 5 格 → 串「太知川天止」第 5 个 = 止 → 草写 → と`

### 拆字法
| 假名 | 拆解 |
|---|---|
| た | 太 → 左边「ナ」，右边「こ」，拆成两块写 |
| ち | 知 → 「知」左半「矢」的草写，一横 + 向**右**弯的钩 |
| つ | 川 → 三竖连笔一气呵成，压扁成一道横弯 |
| て | 天 → 「天」字草写，一笔横起再往左下拉 |
| と | 止 → 「止」草写，一竖 + 一斜挑 |

## 二、⚠️ 两个破格：ち = chi，つ = tsu

**た行 = ta / chi / tsu / te / to**

不是 ta-ti-tu-te-to。破格全表清点：

| 破格 | 位置 | 状态 |
|---|---|---|
| し shi | さ行 い段 | ✅ D3 已学 |
| **ち chi** | **た行 い段** | ✅ **D4 本课** |
| **つ tsu** | **た行 う段** | ✅ **D4 本课** |
| ふ fu | は行 う段 | ⬜ D6 |

规律复习：**破格全部出在い段和う段**，因为 i/u 舌位最高，把前面的辅音带跑了。
- t + i → 舌尖被 i 拖到硬腭 → **chi**
- t + u → 舌尖被 u 拖出摩擦 → **tsu**

**这不是「例外要死记」，是发音的物理必然。** 记住「い段う段容易拧」，四个破格就不用背了。

## 三、⚠️ 发音坑：ち 和 つ 到底怎么读

### ち = 「吉」系，不是「七」系
和 D2 学的送气规则一脉相承：

| | 中文 | 送气? |
|---|---|---|
| ❌ 太用力 | 七 qī | 送气 |
| ✅ 词中的 ち | 吉 jí | 不送气 |
| ✅ 词头的 ち | 介于两者，略带气 | 微送气 |

**默认按「吉」发**，词头稍微带点气就行。手掌测气流法照旧（放嘴前 5 cm，纸片不该被吹动）。

### つ = 「资」系，中文里最接近的是 z
つ 是全表最难的一个，因为普通话没有完全对应的音。

| | 中文 | 为什么 |
|---|---|---|
| ❌ 最常见错法 | 粗 cū | c 是送气的 [tsʰ]，且圆唇 |
| ❌ 次常见错法 | 屈 qū | 完全跑到另一个部位了 |
| ✅ 目标 | **资 zī** 的声母 + **扁唇的 u** | z 就是不送气的 [ts] |

**做法：先说中文「资」，把它拖长成 zzz —— 那个 ts 就对了，然后把嘴唇摊平（う段不圆唇）。**

### た/て/と = 中文的 d，不是 t
- 词中：`と` ≈ 中文「多」的声母 d（不送气）
- 词头：略送气
- `と` 是 to，不是 tuo；`て` 是 te，不是 tie

## 三·补 谐音记忆表（音→音，学习者要求补充）

> **字源串给「形」，谐音串给「音」——两条链，别混用。**
>
> | 用途 | 串 |
> |---|---|
> | 形（怎么写） | **太 知 川 天 止** |
> | 音（怎么读） | **他 吉 资 爹 拖** |

| 假名 | 谐音汉字 | 要做的减法 | 说明 |
|---|---|---|---|
| **た** ta | **他** tā | 词中要**减送气** → 「搭 dā」 | 词头用「他」，词中用「搭」 |
| **ち** chi | **吉** jí | 直接用，别用「七」 | 「七」送气过头 |
| **つ** tsu | **资** zī | 直接用，别用「粗」 | z 正是不送气的 ts，且天然扁唇 |
| **て** te | **爹** diē | **减掉 i 介音** → d-e | 不是「贴」（送气 + 带 i） |
| **と** to | **拖** tuō | **减掉 u 介音** → t-o | 不是「拖」的整音，to ≠ tuo |

**记法压缩成一句：两个破格用整字（吉、资），另外三个做减法（他减气、爹减 i、拖减 u）。**

> ⚠️ 谐音是**拐杖**，不是目的地。た行的音本来就是 `t + あいうえお`，只有 ち/つ 两个破格需要外挂。
> 三个月后你应该直接从网格出音，谐音表会自然废掉。声调（tā/jí/zī）在日语里完全无关，别带进来。

## 四、⚠️ う段圆唇 · 第四次复查
`つ` 是う段。发 tsu 时嘴唇**扁**，不是「粗」的圆唇。
自查法照旧：从 `い` 起手，嘴唇宽度不动，只缩舌头。

## 五、形近对（本课要连着算三笔账）

### ★ さ / ち —— 靠弯的方向（最好用的一条）
```
さ  弯向【左】   ← 字源就是「左」
ち  弯向【右】
```
**さ 来自「左」，钩就朝左。** 字源和字形方向一致，这条钩子最省事。

### ★ さ / き —— 靠数横线（D3 已解决，本课并入）
一横 sa，两横 ki（key 有两道齿）。

### ★ し / つ —— 靠钩的朝向
```
し  竖着下来再钩   ← 纵向，一笔
つ  横着过去再钩   ← 横向，一笔
```
**竖的是 し，横的是 つ。**

### ★ 四字混合闪测组（本课新短板）
`さ き ち そ` 四个字长得像一家人，必须一起练：

| 字 | 一句话锁定 |
|---|---|
| さ | 一横 + 弯朝**左** |
| き | **两横** + 弯 |
| ち | 一横 + 弯朝**右** |
| そ | 一笔**之字折**下来，收成钩、悬空 |

### 顺带预告
- `つ` / `っ`（小写促音，D13）—— 只是尺寸不同
- `て` / `と` 本身不像，但都容易和 D9 的 `ろ/る` 搞混，到时再说

## 六、促音 `っ` 见个面（不考，D13 才正式学）

日语里有个**小写的 つ**，写作 `っ`，占正常假名的一半大。

- 它**不发音**，作用是「停一拍」，把后面的辅音顶住。
- 例：`きって`（切手/邮票）读作 ki—(停一拍)—te，中间那一拍是憋住气不出声。
- 对比 `きて` 是两拍，`きって` 是**三拍**。

> 今天只要求：**看到小 っ 知道它是「停一拍」，不是 tsu。** 别的不管。
